# KH_IX_ORACLE

Hackathon Oracle: predicts which hackathon projects will win, trained on about 3,500 real Devpost
projects from 17 recent college hackathons. Built at Knight Hacks IX.

* `training/`: scraper, model training, validation (see `training/README.md`)
* `backend/`: FastAPI service the frontend calls (see `backend/README.md`)
* `frontend/`: web app
